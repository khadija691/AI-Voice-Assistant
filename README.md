# AI Voice Assistant

A simple AI Voice Assistant built using Python and Streamlit.

## Features

- Speech Recording
- Speech-to-Text using Faster Whisper
- AI Responses using Groq Llama 3
- Text-to-Speech using pyttsx3
- Interactive Streamlit Web Interface

## Technologies

- Python
- Streamlit
- Faster Whisper
- Groq API
- pyttsx3

## Run

```bash
streamlit run streamlit_app.py
